# Product Sense

## What This Product Does

星星乐园是一款家庭激励管理系统，帮助家长通过任务打卡和积分奖励机制激励孩子养成良好习惯。家长可以设置每日任务（如背单词、练字），孩子完成打卡后获得金钱奖励和积分，积分可兑换设定的奖励目标（如玩具）。

## Who Uses It

- **家长**：通过管理后台设置任务、查看统计数据、管理奖励目标、发放积分
- **孩子**：通过小程序进行每日打卡、查看进度和奖励

## Core User Journeys
1. **每日打卡**：孩子在小程序中查看今日任务 → 点击打卡 → 获得奖励
2. **目标追踪**：家长设置奖励目标（如变形金刚玩具 ¥50）→ 孩子每次打卡自动累积进度 → 达成目标
3. **数据统计**：家长查看连续打卡天数、周完成率、30 天趋势图
4. **积分管理**：家长手动发放特殊积分奖励 → 孩子积分余额更新

## Business Rules

- 打卡完成任务后自动计入金钱余额和奖励目标进度
- 连续打卡天数从今天往前计算，今天无打卡则从昨天开始
- 奖励目标达成时自动标记 is_achieved = 1
- 积分与金钱余额是双系统：积分为整数、余额为浮点数
- 种子数据在首次启动时自动初始化（检测 children 表为空时触发）

## Domain Terminology

| 术语 | 含义 |
|------|------|
| 打卡 (Checkin) | 孩子完成一项任务的记录 |
| 任务 (Task) | 家长设定的每日待办事项，附带奖励金额 |
| 奖励目标 (Reward) | 积攒金钱可兑换的目标，有目标金额和当前进度 |
| 积分 (Points) | 独立于金钱的激励单位，家长可手动发放 |
| 连续打卡 (Streak) | 连续有打卡记录的天数 |
| 周完成率 (Weekly Rate) | 本周实际完成打卡数 / 预期打卡数 |
