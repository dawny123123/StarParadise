# 月报模板格式说明

## 整体风格
- 白底、中文、渐变色数字/进度条
- 宽度 560px，使用 wkhtmltoimage 渲染
- 渲染命令：`wkhtmltoimage --width 560 --quality 95 --enable-local-file-access <html> <output.png>`

## 板块结构（从上到下）

### 1. Hero 区
- 标题「健康月报」+ 副标题「YYYY年M月 · N天」
- 三个大数字横排（间距大）：体重变化 / 日均热量 / 运动时长
- 渐变色：绿(#11998e→#38ef7d) / 橙(#f2994a→#f2c94c) / 紫(#667eea→#764ba2)

### 2. 体重板块
- 合并指标卡（圆角灰底卡片，行内展示）：
  - 月初 → 月末
  - 变化
  - 最低 / 最高
  - 记录天数
- 近7天体重趋势折线图（SVG）

### 3. 运动板块
- 合并指标卡：
  - 训练天数 / 次数
  - 总时长 / 消耗
  - 总容量
- 运动分类条形图（渐变色标签 + 进度条）

### 4. 饮食板块
- 每日热量热力图（30格，颜色分级）+ 图例
- 日均营养进度条：热量/蛋白/碳水/脂肪（含目标值+状态标签）

### 5. 总结与亮点板块（合并）
- 6个核心指标一排横排（白底圆角小卡片）：
  - 体重变化 / 热量超标 / 蛋白缺口 / 运动天数 / 补剂 / 记录
- 4个亮点一排横排（白底圆角小卡片）：
  - 最佳日 / 最差日 / 最轻 / 最猛

### 6. 专业建议板块
- 按优先级分类（P0红/P1橙/OK绿）
- 每条包含：问题描述（含具体数据）+ 执行方案（含量化指标）
- 最后一条为下月量化目标

### 7. 页脚
- 日期 · 记录条数 · 小虾健康管家

## HTML模板
- 文件：`monthly-report-template.html`（同目录）
- 每月生成时替换数据即可
