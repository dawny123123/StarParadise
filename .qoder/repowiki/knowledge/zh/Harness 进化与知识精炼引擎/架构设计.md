- **核心编排层**：以 `SKILL.md` 为入口定义六步工作流（Context → Analyze → Refine → Memory → Validate → Report），协调各子脚本执行。
- **分析与诊断层**：`harness_critic.py` 负责从 Failure/Episode 数据中聚类失败模式并计算三维进化评分；`skill_nudge.py` 基于语义相似度检测 Skill 缺失候选。
- **修复与进化层**：`harness_refiner.py` 根据优先级（P0-P3）应用自动化修复；`skill_patcher.py` 提供九级模糊匹配算法安全地修改 Skill 文件内容。
- **记忆与同步层**：`memory_query.py` 管理情景记忆的修剪与知识提取；工作流内置逻辑将任务变更映射到 `docs/` 下的架构与设计文档。
- **参考规范层**：`references/` 目录定义了进化安全约束、反馈流水线机制及 Skill 创建标准，确保进化过程的可验证性与一致性。
