本模块为纯文档仓库，按用途划分为三个子目录：
- `design-docs/`：面向组件的设计文档索引（`index.md`）及后端服务、PC 管理后台、小程序三端的独立设计说明，配合根级 `ARCHITECTURE.md` 中的 L0–L5 分层图与依赖约束表，统一描述 Express + SQLite 后端与 Vue3 前后端的层间边界。
- `exec-specs/`：以“特性”为单位组织的可执行规格，每个特性包含 `spec.md`（需求/数据模型/API/影响范围）、`acceptance.md`（验收标准）和 `tasks.md`（任务拆解），已完成项归档在 `completed/` 下（如 goals-todos-db-persistence、reward-management），未完成项保留在顶层（如 miniprogram-checkin-wallet）。
- 根级文档：`DEVELOPMENT.md` 提供 Node/Python 前置条件与 `make` 命令矩阵；`OPERATIONS.md`、`TESTING.md`、`PRODUCT_SENSE.md`、`api.md`、`产品手册.md`、`产品需求规格模板.md` 分别覆盖运维、测试、产品思维、接口契约、用户手册与需求模板。
依赖方向单向：文档仅引用代码路径作为事实来源（如 `ARCHITECTURE.md` 引用 `star-park/server/src/index.js` 等），不反向被代码依赖。
