- 每个功能任务在 `tasks/` 下建立独立命名目录，并以 `state/task.json` 记录 task_id、status、started_at/completed_at、files_changed/files_created 等元数据。
- 子任务进度通过 `checkpoints/task-N.json` 按序号递增保存，便于断点恢复与增量验证。
- 领域知识与编码约定以 JSON 文档形式沉淀到 `memory/knowledge/{domain,conventions}.json`，并通过 `sources` 字段关联来源任务。
- 功能验证场景以结构化 JSON 描述 HTTP 请求/响应断言（method、url、body_contains），统一写入 `trace/verification-report.json` 的 `task_specific_scenarios` 数组。
- 环境脚本遵循 `set -euo pipefail` 严格模式，并使用 `--- BEGIN PARAMETERIZED ---` 注释块包裹可被外部参数化的部分。
