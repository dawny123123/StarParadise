- 每个测试文件通过 `beforeEach` 调用 `seedTestData()` 获取 child/task/reward 的 ID，并用 `createAgent()` 创建独立 supertest agent。
- 用例按 HTTP 路由分组使用嵌套 `describe('GET/POST/PUT/DELETE /api/...')`，并以 `it('应...')` 描述业务断言。
- 对业务副作用（transactions 写入、children.points_balance 更新、rewards.current_amount 变化）通过 `getTestDb()` 直接执行 SQL 查询断言，而非仅依赖响应体。
- 校验失败场景统一断言 HTTP 状态码为 400/404，并检查返回体中包含中文错误提示（如 '尚未达成'、'余额不足'、'不支持的奖励单位'）。
- 日期相关用例使用 `dayjs().subtract(...)` 构造 yesterday/twoDaysAgo 等相对日期，以验证连续打卡（streak）从今日或昨日向前回溯的业务规则。
