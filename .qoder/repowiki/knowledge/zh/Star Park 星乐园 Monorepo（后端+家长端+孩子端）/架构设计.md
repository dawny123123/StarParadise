根目录 star-park/ 作为 monorepo 容器，聚合三个子工程：server（Express + SQLite，提供 /api/checkins|children|goals|points|rewards|stats|tasks|todos 等 REST 接口）、pc-admin（Vue3 + Vite 家长端，调用同一套 /api/* 进行任务/奖励/积分/统计管理）、miniprogram（uni-app + Vue3 孩子端，调用相同 API 完成打卡/钱包/进度查看）。服务端由 src/app.js 装配路由并注入 database.js 数据层，业务规则（打卡完成自动更新奖励目标进度、进度达标自动标记 is_achieved、连续打卡从今日或昨日向前回溯、周完成率按活跃任务数计算、双货币体系——金钱余额 via transactions 用于兑换、积分 via points 由家长手动发放用于行为激励）集中在 server 层实现，前后端仅通过 JSON 契约耦合。根 Makefile 暴露 build/test/lint/verify 等 target 统一编排，harness/ 提供开发环境启动/销毁脚本，deploy/ 提供 systemd 托管的生产发布与回滚流程，三者共同构成从本地开发到生产部署的完整链路。
