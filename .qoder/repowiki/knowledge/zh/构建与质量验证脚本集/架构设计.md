脚本按职责分为三类：
- Python 静态分析器：`lint-deps.py` 基于 `LAYERS` 字典（L0 数据层→L5 前端入口）扫描 `.js/.vue/.ts` 文件中的 `require/import`，禁止上层导入下层以外的模块并拦截前后端跨子项目直接导入；`lint-quality.py` 扫描源码中 `console.log`、文件大小（默认 ≤500 行），并通过 `KNOWN_EXCEPTIONS` / `KNOWN_LARGE_FILES` 白名单放行例外。
- Shell 工具脚本：`check-db-consistency.sh` 用 `sqlite3` 校验核心表（children/tasks/checkins/rewards/transactions/points）及字段存在性；`code-review-check.sh` 禁止 `debugger` 并统计 TODO；`generate-api-doc.sh` 正则扫描 Express 路由定义；`run-api-tests.sh` 通过 `curl` 调用 `/health`、`/children`、`/tasks`、`/dashboard` 做冒烟测试。
- 编排入口：`validate.py` 顺序执行 build → lint-arch → test → verify，任一阶段失败即中止，支持 `--skip-verify` 跳过端到端验证。
依赖方向单向：所有脚本仅读取 `star-park/` 下的源码与 SQLite 数据库，不反向被业务代码引用。
