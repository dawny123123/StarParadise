模块采用典型 Vue 3 SPA 架构：入口 src/main.js 挂载 Pinia、vue-router 与 Element Plus；根组件 App.vue 仅渲染 <router-view>，页面布局由 components/Layout.vue 组合 SideNav 侧边栏与主内容区构成。路由在 src/router/index.js 中以 Layout 为壳，子路由按业务域划分（dashboard/goals/balance/rewards/best-practices），并通过懒加载 import() 拆分代码，meta.title/meta.icon 配合 beforeEach 动态设置 document.title。状态集中在 stores/app.js 的 Pinia store 中，维护 children 列表、currentChildId、loading 及颜色映射，被 Dashboard/ChildCard 等视图共享。数据访问统一收敛到 api/index.js，基于 axios 实例封装 baseURL=/api 的请求，并按领域（children/tasks/goals/todos/checkins/rewards/stats/dashboard/balance/points/best-practices）导出命名函数；QoderWake 自动化调用通过原生 fetch 直接请求后端代理路径 /qoderwake-api。构建层 vite.config.js 将 /api 代理至本地 3001 端口，将 /qoderwake-api 重写后转发至 https://api.qoder.com，实现前后端联调与第三方自动化能力解耦。
