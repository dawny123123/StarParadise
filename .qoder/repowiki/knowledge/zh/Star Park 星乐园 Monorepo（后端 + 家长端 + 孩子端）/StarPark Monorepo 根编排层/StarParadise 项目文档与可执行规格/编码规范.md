- 每个可执行特性以 `spec.md` + `acceptance.md` + `tasks.md` 三件套形式组织，并在 `exec-specs/completed/` 下归档已完成的实现。
- 设计文档通过 Mermaid graph/sequenceDiagram 表达层依赖图与请求处理时序，并标注来源文件路径以便追溯。
- 新增路由或模块需同步登记到 `scripts/lint-deps.py` 的 `LAYERS` 白名单，否则 `make lint-arch` 会报层违规。
- 数据库变更在 `server/src/database.js` 中以 `CREATE TABLE IF NOT EXISTS` 幂等 DDL 声明，并在 `resetForTest` 表清单中按外键依赖倒序追加以保证测试隔离。
- API 文档由 `make api-doc` 从源码自动生成至 `docs/api.md`，避免手写接口定义与代码脱节。
