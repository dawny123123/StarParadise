测试套件以 `setup.js` 中的全局 `beforeEach` 调用 `db.resetForTest()` 重置 SQLite 数据库作为执行入口；每个 `.test.js` 文件对应一个业务域（checkins、points、rewards、stats、tasks、todos、goals、children、seed），通过 `helpers.js` 提供的共享夹具统一初始化：`createAgent()` 将真实 Express 应用 `../src/app` 挂载为 supertest agent，`seedTestData()` 在每次用例前插入两个 child、若干 task 和 reward 并返回其 ID，`getTestDb()` 暴露底层数据库连接用于直接断言事务副作用（如 transactions、children.points_balance、rewards.current_amount）。依赖方向单向指向被测服务 `../src/*`，测试之间通过独立的 agent 实例与隔离的 SQLite 数据保持完全解耦。
