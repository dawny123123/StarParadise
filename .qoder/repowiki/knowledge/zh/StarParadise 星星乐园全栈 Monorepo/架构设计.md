顶层 Makefile 作为跨子模块的统一入口，将 harness（环境启动/停止）、scripts（架构约束检查、API 文档生成、数据库一致性校验、端到端验证）与 star-park/ 下的三个子应用串联：`make setup-env/start-server/teardown-env` 通过 harness/scripts 驱动 server 进程；`make api-doc/api-test/check-db/lint-arch` 调用 scripts 下对应工具扫描 star-park/server 的 routes 与 database.js；star-park/package.json 提供 `install:all`、`start:server`、`start:pc`、`start:mini` 等脚本在 server、pc-admin、miniprogram 三子目录间切换工作区。三个子应用共享同一份 REST API 契约（由 server/src/routes/* 暴露），前端通过各自 src/api/index.js 调用，形成“单后端 + 双前端”的解耦结构。
