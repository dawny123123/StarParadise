- Bash 脚本统一以 `set -euo pipefail` 开头，并通过 `SCRIPT_DIR=$(cd "$(dirname "$0")" && pwd)` 与 `PROJECT_DIR="$(dirname "$SCRIPT_DIR")"` 推导仓库根目录。
- Python 脚本使用 `if __name__ == "__main__": main()` 作为入口，并在 `main()` 中收集 violations 列表后统一打印、以 `sys.exit(1)` 报告失败。
- 可配置项集中声明在文件顶部常量区（如 `LAYERS`、`RAW_LOG_PATTERNS`、`SKIP_DIRS`、`MAX_FILE_LINES`），并用 `# CUSTOMIZE:` 注释标注，便于二次定制。
- 白名单例外采用 `KNOWN_EXCEPTIONS` / `KNOWN_LARGE_FILES` 字典形式维护，同时支持带 `./` 前缀的路径变体以避免相对/绝对路径匹配不一致。
- Bash 中的参数化区域用 `# --- BEGIN PARAMETERIZED ---` / `# --- END PARAMETERIZED ---` 注释块包裹，便于外部工具或模板替换。
