本模块是纯数据 + Shell 脚本的编排层，不引入运行时依赖，按职责划分为以下目录：
- `config/environment.json`：声明式运行时描述（Node 18+、better-sqlite3、Express 端口、构建/开发命令、功能场景步骤、以及指向 scripts 的入口），被上层编排器读取以驱动生命周期。
- `scripts/{setup-env.sh,start-server.sh,teardown-env.sh}`：幂等 Shell 脚本，负责安装三端依赖、启动后端服务与清理；由 environment.json 的 `scripts.*` 字段统一引用。
- `tasks/<task-id>/state/` 与 `checkpoints/`：每个任务一个子目录，`state/task.json` 记录任务元信息、文件变更集与完成时间，`checkpoints/task-N.json` 保存阶段检查点，形成可回放的任务执行轨迹。
- `memory/knowledge/{domain.json,conventions.json}` 与 `memory/episodes/*.json`：结构化记忆存储，前者沉淀领域事实与编码约定（带来源 task 引用），后者按时间归档任务 episode。
- `trace/`：不可变审计日志，`improvements.jsonl` 追加记录 skill 提示与文档同步事件，`verification-report.json` 汇总端到端验证结果。
- `drafts/skills/`：AI Skill 草稿，以 Markdown front-matter 描述跨 DB→API→pc-admin→miniprogram 的全栈开发流程，作为知识沉淀产物。
- `verify/README.md`：约定 E2E 验证脚本存放位置与退出码语义，配合顶层 `make verify` 调用。
依赖方向单向向外：harness 仅通过 JSON 配置与 shell 脚本驱动 star-park 子工程，自身不被业务代码反向依赖。
