- 页面通过 `src/pages.json` 集中注册路径与 tabBar 图标，页面目录遵循 `pages/<feature>/index.vue` 的扁平结构。
- 所有网络请求统一经 `src/api/index.js` 的 `request` 封装调用，页面只依赖 `api` 命名空间方法，不直接调用 `uni.request`。
- 组件间通过 `<script setup>` 的 `defineProps` / `defineEmits` 进行单向数据流通信，子组件仅接收 props 并发出事件。
- 样式使用 SCSS 配合 BEM 风格类名（如 `page-index`、`child-card__header`），并通过 `uni.scss` 中的 `$primary`、`$text-light` 等变量保持主题一致。
- 页面数据加载在 `onMounted` 与 `onShow` 中重复触发，并在 API 失败时回退到内联默认数据以保证离线展示。
- 双货币体系在前端以独立字段呈现：金钱余额通过 transactions 记录（earn/spend），积分通过 points 记录并由家长手动发放，两者在打卡页统计卡片中并列显示。
