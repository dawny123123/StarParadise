- 每个脚本以 shebang 开头并使用 `set -euo pipefail` 确保严格模式，路径通过 `SCRIPT_DIR` + `PROJECT_DIR` 推导避免硬编码绝对路径。
- 可配置项集中在文件顶部常量（如 `LAYERS`、`MAX_FILE_LINES`、`SKIP_DIRS`、`FORBIDDEN_IMPORTS`），便于按需定制而不修改逻辑。
- 对已知例外使用白名单字典（`KNOWN_EXCEPTIONS`、`KNOWN_LARGE_FILES`）而非全局放宽规则，保持检查严格性。
- Shell 脚本中关键参数与路径段用 `--- BEGIN PARAMETERIZED ---` / `--- END PARAMETERIZED ---` 注释包裹，便于外部工具识别可替换区域。
- Python 脚本统一采用 `main()` + `if __name__ == "__main__"` 结构，通过收集 violations 列表并在末尾统一输出后以非零退出码报告失败。
