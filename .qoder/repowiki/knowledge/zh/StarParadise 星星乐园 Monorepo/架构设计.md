仓库采用三子包 + 共享基础设施的 Monorepo 结构：`server/`（Express + SQLite REST API）提供 `/api/*` 接口；`pc_admin/`（Vue 3 + Vite）作为家长管理后台消费该 API；`miniprogram/`（uni-app）作为孩子打卡端同样通过 HTTP 调用同一套接口，三者之间零代码耦合、仅依赖 HTTP 契约。`scripts/` 提供依赖层级校验、数据库 DDL 一致性检查、API 文档生成等质量工具，由 `validate.py` 统一编排；`harness/` 负责环境初始化、服务启动与端到端任务编排；顶层 `Makefile` 将各子命令统一暴露为 `build/lint-arch/verify/setup-env/start-server/teardown-env` 等目标，`AGENTS.md` 作为开发者入口说明分层架构约束（L0–L5 禁止跨层导入）。业务域围绕孩子、任务、打卡、奖励目标、积分与交易展开，双货币体系在领域模型中严格区分：金钱余额走 transactions（earn/spend），行为激励走 points，所有变更需经 `make verify` 或 `python3 scripts/validate.py .` 串联校验。
