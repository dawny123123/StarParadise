本模块为扁平的脚本集合，按职责分为三类：
- Python 静态分析：`lint-deps.py` 基于 `LAYERS` 字典（L0 数据层→L5 前端入口）对 `.js/.vue/.ts` 进行 import 解析，禁止上层导入下层并拦截跨子项目（前端→后端）导入；`lint-quality.py` 通过正则扫描 `console.log`、文件行数上限（500 行），配合 `KNOWN_EXCEPTIONS` / `KNOWN_LARGE_FILES` 白名单放行已知位置；`validate.py` 作为统一入口，顺序执行 `make build → make lint-arch → make test → [可选] make verify`，任一阶段失败即中止。
- Bash 运行期校验：`check-db-consistency.sh` 用 `sqlite3 PRAGMA table_info` 核对 SQLite 表结构与字段；`run-api-tests.sh` 通过 `curl` 调用 `BASE_URL` 下的 `/health`、`/children`、`/tasks`、`/dashboard` 做健康检查；`code-review-check.sh` 扫描 `debugger` 语句与 TODO 标记；`generate-api-doc.sh` 从 Express `router.get/post/put/delete` 定义提取 API 清单。
- `scripts/verify/README.md` 约定 E2E 场景脚本的命名与退出码契约（成功 0、失败非 0），由 Makefile 的 `verify` 目标统一编排。
所有脚本均以 `#!/usr/bin/env python3` / `#!/bin/bash` + `set -euo pipefail` 开头，通过 `SCRIPT_DIR`/`PROJECT_DIR` 推导仓库根，不依赖绝对路径。
