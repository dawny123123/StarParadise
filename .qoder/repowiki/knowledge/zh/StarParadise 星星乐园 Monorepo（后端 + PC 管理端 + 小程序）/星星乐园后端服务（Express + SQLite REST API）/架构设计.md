单进程 Node.js 应用，入口 `src/index.js` 先调用 `seed()` 初始化种子数据，再启动 `app.listen`；`src/app.js` 通过 `express.Router()` 将 `/api/children|tasks|checkins|rewards|stats|points` 以及 `/api/dashboard` 挂载到对应路由模块，并统一启用 cors 与 JSON 解析中间件，同时暴露 `/api/health` 健康检查。
- 数据层：`src/database.js` 使用 better-sqlite3 同步 API 打开 `data/star-park.db`（测试模式走内存数据库），启动时执行建表 DDL，并通过 try/catch 包裹多条 ALTER TABLE 实现向后兼容的轻量迁移；开启 WAL 模式与外键约束，并提供 `resetForTest()` 供测试重置。
- 业务路由：`src/routes/*.js` 每个文件封装一个资源域的全部 HTTP 处理器，直接调用 `db.prepare(...).all/run/get` 进行 SQL 操作，复杂写路径（如打卡写入 checkins + transactions + rewards 更新）使用 `db.transaction(fn)` 保证原子性。
- 初始化：`src/seed.js` 在首次启动时以事务批量插入示例孩子、任务与奖励目标，若 children 已有记录则跳过。
- 依赖方向：index → app → routes → database；routes 之间无相互引用，数据库连接通过模块单例共享。
