- 所有 SQL 查询统一使用 `db.prepare(sql).all/run/get(...params)` 占位符形式，避免字符串拼接注入。
- 涉及多表写入的写操作（打卡、自动打卡、种子数据）均包裹在 `db.transaction(() => {...})()` 中以保证原子性。
- 路由文件以 `module.exports = router` 暴露 express.Router，并在 `app.js` 中以 `app.use('/api/<resource>', router)` 挂载。
- 错误处理采用 try/catch 捕获后返回 `{ error: err.message }` 的 500 响应体。
- 数据库结构演进通过 `try { db.exec('ALTER TABLE ... ADD COLUMN ...') } catch {}` 的幂等方式实现，不引入外部迁移工具。
- 测试环境通过 `NODE_ENV=test` 切换内存数据库，并在 `tests/setup.js` 的 `beforeEach` 中调用 `db.resetForTest()` 清理数据。
