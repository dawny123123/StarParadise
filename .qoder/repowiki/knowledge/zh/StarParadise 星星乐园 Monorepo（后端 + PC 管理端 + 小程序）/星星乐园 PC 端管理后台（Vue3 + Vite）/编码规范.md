- API 函数按领域分组并以注释分隔（如 `// ========== 任务相关 ==========`），每个资源统一暴露 get/create/update/delete 等命名一致的导出。
- 路由定义采用懒加载 `() => import('../views/Xxx.vue')` 并在 `meta` 中声明中文 `title` 与 Element Plus 图标名，由 `beforeEach` 守卫统一设置浏览器标题。
- Pinia store 使用 Composition API 风格 `defineStore('app', () => { ... })`，将 ref/computed 与异步方法一并 return，避免 Options API 样板。
- 对外部不可控调用（如 QoderWake）直接走原生 fetch 并显式检查 `res.ok`，失败时抛出包含状态码与响应体的 Error，而非吞掉异常。
