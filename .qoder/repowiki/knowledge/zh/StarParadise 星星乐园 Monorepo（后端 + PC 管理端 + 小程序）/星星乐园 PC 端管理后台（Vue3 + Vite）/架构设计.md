单页应用，入口 `src/main.js` 统一创建并挂载 Pinia、Vue Router 与 Element Plus（含图标全局注册），根组件 `App.vue` 仅包含 `<router-view />`。
- 路由层：`router/index.js` 以 `Layout` 为外层容器，通过懒加载 `() => import('../views/Xxx.vue')` 组织各业务视图，并在 `meta` 中声明中文 title 与 Element Plus 图标名，由 `beforeEach` 守卫统一设置浏览器标题。
- 状态层：`stores/app.js` 使用 Pinia Composition Store 维护孩子列表、当前选中孩子及颜色映射，供侧边栏与子视图共享。
- 网络层：`api/index.js` 基于 axios 创建实例（baseURL=/api，10s 超时），集中导出 children/tasks/checkins/rewards/stats/balance/points 等 RESTful 接口；对外部不可控调用（QoderWake）直接走原生 fetch 并显式检查 `res.ok`，失败时抛出包含状态码与响应体的 Error。
- 构建与代理：`vite.config.js` 配置开发服务器端口 5174，将 `/api` 反向代理至本地后端 `http://localhost:3001`，并将 `/qoderwake-api` 重写为 `https://api.qoder.com/v1/qoderwake` 直连外部服务。
- 视图按功能域拆分到 `views/` 目录，公共布局与导航抽离在 `components/Layout.vue`、`SideNav.vue`、`ChildCard.vue` 中，样式集中在 `styles/main.css`。
