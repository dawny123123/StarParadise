- **技术架构**：采用 Vite + Vue 3 (Composition API) + Pinia + Vue Router 的现代化前端技术栈，UI 组件库选用 Element Plus。
- **目录结构**：遵循标准 Vue 项目分层，`src/api` 封装 Axios 实例与业务接口，`src/stores` 使用 Pinia 管理全局状态（如当前选中儿童信息），`src/views` 承载仪表盘、任务、奖励等七大核心业务页面，`src/components` 提取通用布局（Layout/SideNav）与业务卡片组件。
- **数据流设计**：通过 `api/index.js` 统一处理后端请求与响应拦截，视图层通过组合式 API 调用 Store 或直接请求 API，实现多儿童维度的动态数据过滤与展示（如任务管理中的 Tab 切换）。
- **路由配置**：采用嵌套路由模式，`Layout` 作为根组件承载侧边导航，子路由通过懒加载方式引入各业务视图，并在路由守卫中动态设置页面标题。
