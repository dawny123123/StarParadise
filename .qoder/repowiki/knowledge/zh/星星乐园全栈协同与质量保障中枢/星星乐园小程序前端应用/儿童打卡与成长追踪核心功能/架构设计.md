- **页面层**：包含首页仪表盘 (`index/index.vue`)、打卡执行页 (`checkin/index.vue`) 和记录查询页 (`records/index.vue`)，均采用 Vue 3 Composition API (`<script setup>`)。
- **组件层**：复用 `ChildCard`（展示卡片）、`TaskItem`（任务项）和 `PointsModal`（积分弹窗）等通用 UI 组件，实现视图逻辑解耦。
- **数据交互层**：通过 `@/api/index.js` 封装统一的 `uni.request` 请求，处理与后端的 RESTful 接口通信（如 `/dashboard`, `/checkins`, `/children`）。
- **状态管理**：采用组件内局部状态 (`ref`, `computed`) 管理当前选中子女、任务完成状态及日历数据，通过 `onShow` 钩子确保页面切换时数据实时刷新。
