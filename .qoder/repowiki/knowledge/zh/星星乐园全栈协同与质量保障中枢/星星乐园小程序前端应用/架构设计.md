- **路由与导航编排**：通过 `pages.json` 统一定义页面栈与底部 TabBar，将核心功能（首页、打卡、记录、钱包、我的）映射为标准化导航入口。
- **生命周期管理**：在 `App.vue` 中集中处理小程序全局生命周期（Launch/Show/Hide），并注入全局样式变量，确保视觉一致性。
- **开发环境代理**：利用 `vite.config.js` 配置本地开发代理，统一拦截 `/api` 请求转发至后端服务，解耦前端开发与后端部署依赖。
- **模块化组装**：作为宿主应用，通过 Vue 组件系统按需加载 `core_features` 与 `user_assets` 的业务页面，并复用 `shared_infra` 提供的 API 客户端与 UI 原子组件。
