- **统一编排入口**：根目录 `Makefile` 作为核心调度器，将环境配置 (`setup-env`)、服务启动 (`start-server`) 及多维度检查（架构、API、数据库一致性）委托给 `scripts/` 和 `harness/` 模块执行。
- **跨模块契约校验**：通过 `scripts/` 中的 Shell 脚本实现跨层级的静态与动态验证，如从后端路由源码生成 API 文档、校验 SQLite DDL 与代码实体的一致性、以及针对多端源码的编码规范扫描。
- **Agent 驱动的基础设施**：`harness/` 模块提供标准化的环境生命周期管理（安装依赖、健康检查），并集成 Spec-Driven Development (SDD) 工作流，确保复杂功能在跨模块修改时的规划与记录闭环。
- **文档即契约**：`docs/` 模块不仅存储设计文档，更作为 `scripts/` 自动化生成的产物（如 `api.md`）的承载地，实现了代码实现与技术文档的自动同步。
