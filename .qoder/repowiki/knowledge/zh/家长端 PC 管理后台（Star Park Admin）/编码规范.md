- API 层按业务域分组注释并以命名函数导出 CRUD 方法，统一基于 axios 实例发起请求。
- 视图组件使用 <script setup> 语法，通过 ref/computed/onMounted 组织响应式逻辑，并在 onMounted 钩子中触发数据获取。
- 路由定义集中于 router/index.js，每个子路由通过 meta.title 与 meta.icon 声明标题与侧边栏图标，配合 beforeEach 动态设置 document.title。
- 跨页面共享状态（children、currentChildId、loading）统一放在 Pinia store 中，通过 useAppStore() 注入各组件，避免 prop drilling。
- 外部服务调用（如 QoderWake）通过 import.meta.env.VITE_* 读取运行时配置，并在缺失时主动抛出带上下文的错误信息。
