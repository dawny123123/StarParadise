根目录 star-park/ 作为 monorepo 容器，聚合三个子工程：server（Express + SQLite 提供 /api/checkins|children|goals|points|rewards|stats|tasks|todos 等 REST 接口）、pc-admin（Vue3 家长端，调用同一套 /api/* 进行任务/奖励/积分/统计管理）、miniprogram（uni-app 孩子端，调用相同 API 完成打卡/钱包/进度查看）。服务端由 src/app.js 装配路由并注入数据库层，所有业务规则（打卡完成更新奖励目标进度、达标标记 is_achieved、连续打卡回溯、周完成率按活跃任务计算）集中在 server 层实现，前后端仅通过 JSON 契约耦合。根 Makefile 统一编排 build/test/lint/verify，harness/ 提供开发环境启动/销毁脚本，deploy/ 提供 systemd 托管的生产发布与回滚流程，三者共同构成从本地开发到生产部署的完整链路。
