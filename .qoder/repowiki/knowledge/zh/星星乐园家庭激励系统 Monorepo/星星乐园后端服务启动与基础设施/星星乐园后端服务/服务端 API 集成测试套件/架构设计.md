测试套件围绕 `setup.js` 中的全局 `beforeEach`（调用 `db.resetForTest()`）与 `helpers.js` 提供的共享夹具构建：`createAgent()` 通过 supertest 挂载 `../src/app` 启动真实 Express 应用进行 HTTP 请求；`seedTestData()` 在 SQLite 中插入两个 child、若干 task 和 reward 作为统一初始数据；`getTestDb()` 暴露底层数据库连接以便直接断言事务副作用（如 transactions、children.points_balance）。每个 `.test.js` 文件对应一个业务域（checkins、points、rewards、stats、tasks、todos、goals、children、seed），通过 `describe` 按路由分组组织用例，依赖方向单向指向被测服务 `../src/*`，不反向耦合。
