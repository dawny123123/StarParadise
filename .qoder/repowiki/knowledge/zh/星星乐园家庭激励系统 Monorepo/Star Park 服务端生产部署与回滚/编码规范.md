- 所有脚本顶部启用严格模式（`set -Eeuo pipefail` 或 `set -uo pipefail`），并通过 `log()` / `fail()` 函数统一输出格式和错误退出。
- 版本发布采用 releases 目录 + `current` 软链的蓝绿切换模式，切换时使用 `.tmp` 中间文件配合 `mv -Tf` 实现原子替换。
- 健康检查统一通过 `health-check.sh` 轮询 `/api/health` 并匹配 `"status":"ok"` 响应体，部署与回滚流程均复用该脚本。
- 数据目录通过软链挂载到 `shared/data`，使不同 release 共享同一份 SQLite 数据库，避免版本切换导致数据丢失。
- systemd unit 使用 `ProtectSystem=full` 配合 `ReadWritePaths` 白名单限制写权限，仅允许写入 `/opt/star-park` 与 `/var/log/star-park`。
