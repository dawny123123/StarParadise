仓库采用三子包 + 共享基础设施的 Monorepo 结构：`star-park/server`（Express + better-sqlite3）提供 `/api/*` REST 接口；`star-park/pc-admin`（Vue 3 + Vite）作为家长管理后台消费该 API；`star-park/miniprogram`（uni-app）作为孩子打卡端同样通过 HTTP 调用同一套接口，三者之间零代码耦合、仅依赖 HTTP 契约。顶层 `Makefile` 将各子命令统一暴露为 `build/lint-arch/verify/setup-env/start-server/teardown-env/api-doc/check-db` 等目标，由 `scripts/validate.py` 串联执行依赖层级校验、DDL 一致性检查、API 文档生成与端到端冒烟测试；`harness/` 负责环境初始化、服务启动与按任务维度持久化执行状态。业务域围绕孩子、任务、打卡、奖励目标、积分与交易展开，双货币体系在领域模型中严格区分：金钱余额走 transactions（earn/spend），行为激励走 points，所有变更需经 `make verify` 或 `python3 scripts/validate.py .` 串联校验。
